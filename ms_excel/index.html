M1 Getting Started with Excel +
Learning Objectives

Explain Excel's value in healthcare; navigate the interface and Quick Access Toolbar; use keyboard shortcuts and templates (Patient Logs); access help resources.

Topics Covered
  • Introduction to Excel for healthcare professionals
  • Interface navigation and ribbons
  • Useful keyboard shortcuts
  • Getting help
  • Working with patient log templates

Learning Objectives

Create, save, and organise department/ward workbooks; manage individual worksheets; add, edit, and navigate patient data; use Flash Fill for auto-formatting.

Topics Covered
  • Creating and saving workbooks (Ward Admission Register)
  • Managing worksheets per department
  • Entering and editing patient data
  • Navigating cells, rows, and columns

M3 Basic Formulas and Functions +
Learning Objectives

Write simple formulas; use SUM, COUNT, AVERAGE, MIN, and MAX in clinical contexts; differentiate absolute and relative referencing; use Autosum, Autofill, and error-handling.

Topics Covered
  • How formulas and functions work
  • SUM (admissions, drug quantities)
  • COUNT (patient counts)
  • AVERAGE (age, wait time)
  • MIN and MAX (hospital stay lengths)
  • Absolute vs. relative referencing
  • Autosum, Autofill, and error handling
M4 Formatting for Clarity +
Learning Objectives

Format cells, rows, and columns for readability; apply date and time formats; use Format Painter, cell styles, and colour-coding; protect worksheets and lock patient data.

Topics Covered
  • Cell, row, and column formatting (critical lab values)
  • Number, date, and time formats (DOB, admission date)
  • Format Painter
  • Cell styles and ward colour-coding
  • Sheet and workbook protection

M5 Data Validation and Quality Control +
Learning Objectives

Set up data validation rules and error alerts; apply conditional formatting for data visualisation; use basic and advanced sorting and filtering techniques.

Topics Covered
  • Data validation (preventing invalid age/dates)
  • Error handling and alerts
  • Conditional formatting (flagging abnormal results)
  • Sorting data by date or ward
  • Filtering, AutoFilter, and advanced filter techniques

Learning Objectives

Use IF statements, nested IFs, and IFS for clinical decision flags; apply VLOOKUP, HLOOKUP, INDEX, MATCH, XLOOKUP, XMATCH, OFFSET, and INDIRECT; handle lookup errors.

Topics Covered
  • IF statements (overdue patient reviews)
  • Nested IFs and IFS
  • Multiple criteria conditional IFs
  • VLOOKUP and HLOOKUP
  • INDEX and MATCH
  • XLOOKUP and XMATCH
  • OFFSET and INDIRECT functions
M7 Date and Time Functions +
Learning Objectives

Calculate patient age and length of stay; use WORKDAY, NETWORKDAYS, DATEDIF, EDATE, and EOMONTH for scheduling and monthly reporting.

Topics Covered
  • How Excel stores dates and times

  • WORKDAY and WORKDAY.INTL (appointments)
  • NETWORKDAYS (working days between admission and discharge)
  • DATEDIF, EDATE and EOMONTH
M8 Sorting, Filtering, and Unique Data +

Sort data across multiple columns and custom lists; use dynamic SORT, SORTBY, UNIQUE, and FILTER functions to build dynamic patient lists.

Topics Covered

  • FILTER function for dynamic patient lists
